# Tank Playground

An interactive 3D tank viewer and battle game in a single HTML file, with no external libraries. It draws everything with its own software renderer, so it runs in browsers where WebGL is unavailable.

Open `index.html` in a browser to run it.

## What's in it

- **Blueprint viewer** for the fictional KT-2251S "Project Chaos" super-tank: exterior, gun and autoloader, missile system and suspension, each as an orbitable 3D sheet with callouts, a title block and a live scale bar.
- **Thirteen real tanks** to inspect, each with its own tank, gun and suspension sheets: IS-2, IS-3, Tiger I, Tiger II, Panther, M26 Pershing, M4A3E8 Sherman, T29, T-34-85, M1A2 Abrams, Leopard 2A7, T-90M and Challenger 2. The Tiger I and T-34-85 have purpose-built models; the rest share a parametric template.
- **Battle mode**: drive any of the fourteen tanks against modern or WWII opponents on rolling terrain. Armour is judged on effective thickness, using the real slope of the plate each shell strikes.

| Sound | M | |

## Accuracy

The KT-2251S is fictional. Dimensions, armour and gun figures for the real tanks are approximate and were entered from memory rather than checked against a source. The models are simplified and are not exact replicas.
